# SAT1200+ Math — Book 1 (Foundation) Topic Order Plan

Goal: put every topic in Book 1 in order from **easiest to hardest**, so each lesson
only uses skills taught in earlier lessons.

Book 1 is the foundation book ("SAT 0-1"). It takes a student from basic arithmetic
to linear equations and systems. Harder SAT topics go into Book 2 (see the end of this plan).

**The order of these 5 lessons is already correct.** Exponents and radicals stay after
equations, because rational exponents and exponent rules with variables are harder
than solving a linear equation.

**Gaps (why we need new lessons in between):**

1. **Fractions uses EKUB/EKUK (GCF/LCM), but no lesson teaches them.** A lesson on
   factors and multiples must come before Fractions.
2. **Lesson 1 Set 6 ("Mixed Operations Review") needs order of operations, but the
   Concepts page doesn't teach it.** Also, Sets 1-4 use only positive numbers. There
   are no problems that add, subtract, multiply or divide negative numbers.
3. **No decimals, percents, or ratios/proportions.** These come up a lot on the SAT
   (Problem-Solving & Data Analysis), and the SAT phrase page already uses
   "Round to the nearest tenth".
4. **Nothing after equations:** there are no lessons on inequalities, word problems,
   graphs, lines, functions, or systems. These are the core of SAT Algebra.

### Why this order

- **1 → 2 → 3:** You need whole-number operations to find factors, and factors
  (EKUB/EKUK) to simplify and add fractions.
- **3 → 4 → 5:** Decimals are another way to write fractions (tenths, hundredths),
  and a percent is a fraction or decimal out of 100.
- **5 → 6:** Unit 1 is arithmetic only, with no letters. Unit 2 brings in variables.
- **7 → 8:** Solving a proportion (x/4 = 3/8) is solving an equation, so ratios and
  proportions come after equations. Simple ratio/rate ideas can already be used in
  Lesson 5 (percents) without variables.
- **7 → 9:** Exponent rules with variables and rational exponents are harder than
  linear equations, so they come after (same as now).
- **7 → 10:** Inequalities are solved like equations, plus one new rule: when you
  multiply or divide by a negative, flip the sign.
- **11 first in Unit 3:** Turning English sentences into equations is the most
  common SAT skill. It uses Lessons 5-10 and gets students ready for word-based
  graph and function questions.
- **12 → 13 → 14 → 15:** points → slope → the equation of a line → reading a line as
  a function in real-life problems → two lines together (systems). Systems are the
  hardest topic, so they come last.

## 3. What each lesson should contain

All lessons use the current layout: **Concepts, Vocabulary (EN - UZ), then Sets 1-7**
(Sets 1-6 go from easy to hard; Set 7 is the Challenge).
The Uzbek words are suggestions, so please check them before printing.

### Lesson 1: Basic Arithmetic Operations (current L1, small additions)
- Keep everything that is there now.
- **Add a concept:** Order of operations (Amallar tartibi): brackets → exponents →
  × ÷ (left to right) → + − (left to right). Set 6 already needs this.
- **Add a concept:** Sign rules for negative numbers:
  (−)×(−)=+, (−)×(+)=−, adding and subtracting negatives on the number line.
- **Add a set** (or change one), e.g. "Operations with Negative Integers":
  −3 + 8, −7 − 5, (−4)×(−6), −36 ÷ 9, and so on.
- Absolute value |x| (distance from 0) fits well here as a short concept.

### Lesson 2: Factors, Multiples and Divisibility (NEW)
- Concepts: factor, multiple, prime and composite numbers, divisibility rules
  (2, 3, 5, 9, 10), prime factorization, GCF (EKUB), LCM (EKUK), remainder.
- Sets: list factors → list multiples → prime or not → prime factorization →
  GCF → LCM → Challenge (word problems: "buses leave every 12 and 18 minutes…").
- Vocabulary: Prime number - Tub son · Composite number - Murakkab son ·
  Multiple - Karrali · Divisible - Bo'linadigan · Remainder - Qoldiq ·
  Greatest Common Factor - EKUB · Least Common Multiple - EKUK ·
  Prime factorization - Tub ko'paytuvchilarga ajratish.

### Lesson 3: Fractions (current L2)
- No changes to the content. Its EKUB/EKUK examples now refer back to Lesson 2.

### Lesson 4: Decimals and Rounding (NEW)
- Concepts: place value (tenths, hundredths, thousandths), comparing decimals,
  + − × ÷ with decimals, rounding, fraction ↔ decimal conversion.
- Sets: place value → compare → add/subtract → multiply → divide → round →
  Challenge (convert and compute with mixed fractions and decimals).
- Vocabulary: Decimal - O'nli kasr · Place value - Xona qiymati · Tenth - O'ndan bir ·
  Hundredth - Yuzdan bir · Round - Yaxlitlamoq · Estimate - Taxmin qilmoq · Digit - Raqam.

### Lesson 5: Percents (NEW)
- Concepts: percent = "out of 100"; percent ↔ fraction ↔ decimal; percent of a number;
  what percent A is of B; percent increase/decrease; multiplier method
  (×1.2 for +20%, ×0.8 for −20%).
- Sets: convert → percent of a number → find the percent → increase → decrease →
  discount/tax word problems → Challenge (two changes in a row, e.g. +20% then −20%).
- Vocabulary: Percent - Foiz · Increase - Oshish · Decrease - Kamayish ·
  Discount - Chegirma · Original value - Boshlang'ich qiymat · Tax - Soliq.

### Review 1 + Vocabulary 1
- The current "Number Problems: Lessons 1 & 2" page stays (it becomes Lessons 1 & 3),
  and review problems are added for Lessons 2, 4 and 5.
- The vocabulary list covers Lessons 1-5 only.

### Lesson 6: Algebraic Expressions (current L3)
- No changes to the content. Optional: add "evaluate an expression when x = 3"
  (substitution), because the SAT phrase page uses "Evaluate when x = 3".

### Lesson 7: One-Variable Equations (current L4)

### Lesson 8: Ratios, Rates and Proportions (NEW)
- Concepts: ratio a:b, equivalent ratios, unit rate, proportion and cross-multiplying,
  unit conversion (km/h ↔ m/s, minutes ↔ hours), scaling a recipe or map.
- Sets: simplify ratios → unit rates → solve proportions → unit conversion →
  ratio word problems → Challenge (sharing in a ratio 2:3:5, combined rates).
- Vocabulary: Ratio - Nisbat · Rate - Tezlik · Proportion - Proporsiya ·
  Unit rate - Birlik tezligi · Cross-multiply - Ayqash ko'paytirish ·
  Convert - Aylantirmoq · Unit - O'lchov birligi.

### Lesson 9: Exponents and Radicals (current L5)
- No changes to the content.

### Lesson 10: Linear Inequalities (NEW)
- Concepts: < > ≤ ≥, showing a solution on a number line, solving like an equation,
  **flip the sign when you multiply or divide by a negative**, compound inequalities.
- Sets: read and graph → one-step → two-step → negative coefficient → variables on
  both sides → compound → Challenge (word problems: "at most", "at least").
- Vocabulary: Inequality - Tengsizlik · At least - Kamida · At most - Ko'pi bilan ·
  Solution set - Yechimlar to'plami · Interval - Oraliq · Number line - Son o'qi.

### Review 2 + Vocabulary 2
- Move the current "Number Problems: Lessons 3 & 4", "Lesson 5" and
  "Word Problems: Lessons 3-5" pages here, and add Lessons 8 and 10.

### Lesson 11: Word Problems → Equations (NEW)
- Concepts: key words → symbols ("more than" +, "less than" −, "twice" 2x,
  "per" ÷, "is" =), defining the variable, checking the answer.
- Sets: translate phrases → translate sentences → age problems → money/cost →
  consecutive numbers → mixture/distance (d = rt) → Challenge (SAT-style multi-step).
- Vocabulary: Translate - Tarjima qilmoq · Total - Jami · Difference - Ayirma ·
  Twice - Ikki marta · Per - Har bir · Consecutive - Ketma-ket.

### Lesson 12: Coordinate Plane and Slope (NEW)
- Concepts: x-axis, y-axis, origin, quadrants, plotting (x, y), slope = rise/run =
  (y₂−y₁)/(x₂−x₁), positive/negative/zero/undefined slope.
- Vocabulary: Coordinate plane - Koordinata tekisligi · Axis - O'q ·
  Origin - Koordinata boshi · Ordered pair - Tartiblangan juftlik ·
  Slope - Burchak koeffitsienti · Quadrant - Chorak.

### Lesson 13: Graphing Lines: y = mx + b (NEW)
- Concepts: slope-intercept form, y-intercept, graphing from an equation, writing the
  equation from a graph, two points or slope + point, parallel lines (same slope),
  perpendicular lines (slopes −1/m), standard form Ax + By = C.
- Vocabulary: y-intercept - y o'qini kesish nuqtasi · Parallel - Parallel ·
  Perpendicular - Perpendikulyar · Graph - Grafik · Line - To'g'ri chiziq.

### Lesson 14: Linear Functions and Their Meaning (NEW)
- Concepts: f(x) notation, input/output tables, evaluating f(3), slope as rate of
  change, intercept as starting value, **reading slope and intercept in context**
  (e.g. "C = 15 + 4h: what does 4 mean?"). This comes up on almost every SAT.
- Vocabulary: Function - Funksiya · Input - Kirish qiymati · Output - Chiqish qiymati ·
  Rate of change - O'zgarish tezligi · Linear - Chiziqli · Starting value - Boshlang'ich qiymat.

### Lesson 15: Systems of Two Linear Equations (NEW)
- Concepts: what a solution to a system means (the intersection point), substitution,
  elimination, one solution / no solution (parallel) / infinitely many (same line),
  system word problems.
- Sets: check if a point is a solution → substitution → elimination (easy) →
  elimination (multiply first) → number of solutions → word problems → Challenge.
- Vocabulary: System - Sistema · Substitution - O'rniga qo'yish usuli ·
  Elimination - Qo'shish usuli · Intersection - Kesishish nuqtasi ·
  No solution - Yechimi yo'q · Infinitely many solutions - Cheksiz ko'p yechim.

### Review 3 + Vocabulary 3 + Book 1 Final Test
- Final test: mixed problems from all 15 lessons, written in SAT wording
  (multiple choice plus a few student-produced answers).

## 4. What is NOT in Book 1 (goes to Book 2)

This keeps Book 1 a real foundation book. Book 2 covers the rest of the SAT content
needed for 1200+:

- **Advanced Math:** polynomials, factoring, quadratics (factoring, the quadratic formula,
  vertex form), exponential growth/decay, nonlinear functions, rational expressions.
- **Problem-Solving & Data:** mean/median/mode/range, reading tables and charts,
  scatterplots and lines of best fit, probability, sampling and margin of error.
- **Geometry & Trigonometry:** angles and lines, triangles, the Pythagorean theorem,
  area/perimeter/volume, circles, right-triangle trig (sin, cos, tan).
- **SAT strategy:** Desmos calculator use, plugging in answers, and timing.

(If Book 1 should also cover a little geometry or data, the easiest place is a
short "Basic Statistics: mean, median, mode" lesson after Percents. It only needs
arithmetic.)
