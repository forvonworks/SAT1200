## Answer Key

Each entry: answer, a short worked solution, and the trick used.

### Set 1 — Bridge: the core moves

1. **C ($15$)** — No solution means parallel, distinct lines: $\dfrac k5=\dfrac{12}{4}=3$, so $k=15$. The constants do not follow the ratio ($3\cdot7=21\ne9$), so the lines are distinct. ($\frac53$ inverts the ratio; $3$ is the ratio itself.)  *Trick: Ratio test (a : b : c)*

2. **Ans. 16** — Infinitely many solutions means the equations are multiples of each other. $21=3\cdot7$, so multiply the first by $3$: $6x+21y=3b$. Then $a=6$ and $3b=30$, $b=10$, so $a+b=16$.  *Trick: Ratio test (a : b : c)*

3. **A ($-8x+22y=-5$)** — Rearrange: $4x-11y=10$. No solution needs the same slope but a different constant. $-8x+22y=-20$ would be the same line ($-2$ times everything); with $-5$ the lines are parallel. ($8x-22y=20$ is the same line; the other two cross it.)  *Trick: Which equation could be the second?*

4. **D ($\$1.50$)** — Subtract: $2m=6$, so a muffin is \$3.00. Then $4b=15-9=6$ and $b=\$1.50$. (\$3.00 is the muffin; \$6.00 is $4b$ before dividing by 4; \$4.00 comes from subtracting $5$ instead of $5\cdot3$.)  *Trick: Subtract the equations*

5. **B** — $x=0$ notebooks and $y=120$ binders: $5\cdot120=600$. The first coordinate is the number of notebooks. (Choice A swaps the coordinates: $3\cdot120=360\ne600$.)  *Trick: What does the point mean?*

6. **A ($-6$)** — Slope of $\ell$ is $\frac{13-5}{6-2}=2$, so $m$ is $y=2x+b$. Through $(1,-4)$: $-4=2+b$, $b=-6$. (2 is the slope; $-4$ is just the given $y$-coordinate.)  *Trick: Parallel: same slope*

7. **B ($6$)** — The given slope is $-\frac23$, so $q$ has slope $\frac32$. From $(10,6)$ down to $y=0$ is $6$ units, i.e. $6\div\frac32=4$ units left: $x=6$. (Slopes $\frac23$, $-\frac32$, $-\frac23$ give $1$, $14$, $19$.)  *Trick: Perpendicular: negative reciprocal*

8. **C ($3$)** — $4x-6=14$ gives $x=5$; $4x-6=-14$ gives $x=-2$. The sum is $3$. (Each single case, or the difference $7$, is a trap.)  *Trick: Absolute value: two cases*

9. **B ($-4$)** — The left side is $7x-3k$, so the $x$-terms already match. The constants must match too: $-3k=12$, so $k=-4$. (Forgetting to divide by $-3$ gives $-12$.)  *Trick: Identity: match the constants*

10. **Ans. 11** — $6x-15<4x+9$, so $2x<24$ and $x<12$. The inequality is strict, so $12$ itself fails and the greatest integer is $11$.  *Trick: Inequality: strict at the boundary*

11. **D $(2,3)$** — $(2,3)$: $3>1$ and $5<6$, both true. $(0,6)$ fails $6<6$; $(4,1)$ fails $1>5$; $(6,3)$ fails both.  *Trick: Test each point in both inequalities*

12. **Ans. 11/4** — Slope $=\frac{-13-19}{6-(-2)}=-4$, so $f(x)=-4x+11$ (using $f(-2)=8+11=19$). Then $-4x+11=0$ gives $x=\frac{11}4$. (Enter 11/4 or 2.75.)  *Trick: Linear function from two points*

### Set 2 — Systems with parameters: none, one or infinitely many solutions

1. **C ($6$)** — Parallel needs $\frac k4=\frac9k$, so $k^2=36$ and $k=\pm6$. For $k=-6$ the second equation is $-\frac23$ times the first (the same line: infinitely many solutions). For $k=6$, scaling the first by $\frac23$ gives $4x+6y=4\ne-4$: parallel, no solution.  *Trick: Ratio test (a : b : c)*

2. **Ans. 5.1** — The equations must be the same line. Multiply the first by $\frac92$ so that $2$ becomes $9$: $\frac32x+\frac{18}5y=9$. Then $p+q=\frac32+\frac{18}5=\frac{51}{10}=5.1$.  *Trick: Ratio test (a : b : c)*

3. **A ($-10x+8y=-5$)** — Rearrange: $5x-2y-6=2y+14$ gives $5x-4y=20$. No solution needs coefficients in the ratio $5:-4$ but a different constant. $-10x+8y=-5$ is $-2$ times the left side, yet $-2\cdot20=-40\ne-5$: parallel. ($10x-8y=40$ is the same line; $4x+5y=20$ and $5x+4y=20$ cross it.)  *Trick: Which equation could be the second?*

4. **D ($6x-5y=30$)** — Multiply by the common denominator $15$: $6x-5y=30$. That is the same line, so there are infinitely many solutions. ($5x-6y=30$ swaps the coefficients, $6x-5y=15$ is parallel, $6x+5y=30$ has a different slope.)  *Trick: Clear the fractions*

5. **B ($8$)** — Put $x=2$ in the second equation: $10+2by=18$, so $by=4$. Then the first gives $2a+4=20$ and $a=8$. (Taking $by=9$ gives 5.5; $by=8$ gives 6; ignoring $by$ gives 10.)  *Trick: Substitute the known coordinate*
