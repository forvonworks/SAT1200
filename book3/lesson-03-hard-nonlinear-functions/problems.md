## Answer Key

Each entry: the answer, a short worked solution that uses the shortcut, and the trick used.

### Set 1 — Bridge: read the function before you compute

1. **A ($9$)** — In $a(x-h)^2+k$ with $a<0$ the maximum value is $k=9$ (it happens at $x=-4$). The traps: $-4$ is where the maximum happens, $4$ is the sign slip on $h$, and $-2$ is just $a$.  *Trick: Vertex form reads h and k*

2. **B (The car's value drops by $15\%$ each year.)** — Each year the value is multiplied by $0.85=1-0.15$, so it drops by $15\%$. (Choice $85\%$ confuses the factor with the rate; $0.85\%$ forgets to convert a decimal to a percent.)  *Trick: Growth factor = 1 ± rate*
