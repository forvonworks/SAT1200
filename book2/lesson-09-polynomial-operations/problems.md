## Set 1 — Add/Subtract (the subtraction-sign trap is the headline skill)

Each expression below is the sum or difference of two polynomials. Which polynomial, written in standard form, is equivalent to each expression?

1. $(3x^2+2x-5)+(x^2-4x+7)$
2. $(5x^3-2x+1)-(2x^3+3x-4)$
3. $(-2x^2+6x-3)+(4x^2-6x+8)$
4. $(6x^2-3x)-(2x^2-3x+5)$
5. $(x^3+2x^2-x)+(-x^3+5x-3)$
6. $(4x^2+7)-(x^2-2x+7)$

## Set 2 — Multiply Binomials (FOIL)

Which polynomial, written in standard form, is equivalent to each product below?

1. $(x+3)(x+5)$
2. $(x-2)(x+7)$
3. $(2x+1)(x-4)$
4. $(x-6)(x-6)$
5. $(3x+2)(3x-2)$
6. $(x+4)(2x^2-x+3)$

## Set 3 — Harder Multiply (squares, binomial×trinomial, three factors)

For each expression below, which polynomial in standard form is equivalent to it?

1. $(x+2)^2$
2. $(2x-1)^2$
3. $(x^2+3x-2)(x+4)$
4. $(x-1)(x^2+x+1)$
5. $(3x+1)(x^2-2x+5)$
6. $(x+2)(x-2)(x+1)$

## Set 4 — Division

What is the quotient when each polynomial below is divided by the given divisor? State whether the division is exact (no remainder).

1. $(6x^3-9x^2+3x) \div 3x$
2. $(8x^2+12x) \div 4x$
3. $(10x^4-5x^3+15x^2) \div 5x^2$
4. $(x^2+5x+6) \div (x+2)$
5. $(x^2-9) \div (x-3)$
6. $(2x^2+7x+3) \div (2x+1)$

## Set 5 — Mixed (combine operations in one problem — real test density)

Each expression below combines more than one operation. Which polynomial in standard form is equivalent to each expression?

1. $(x+3)(x-2) - (x^2-5)$
2. $(2x-1)(x+4) + (x^2+3x)$
3. $(x+5)^2 - (x^2+10)$
4. $(3x^2-2x+1) - (x+2)(x-1)$
5. $2(x+1)(x-1) + (x^2-3)$
6. $(x-4)^2 + (8x-10)$

## Set 6 — Spot the Error

Each item below contains exactly one computational error in simplifying the given expression. Identify the error, then state the correct equivalent expression.

1. $(x^2+3x) - (x^2-2x+5)$ — *"$x^2+3x-x^2-2x+5=x+5$."*
2. $(x+3)(x-4)$ — *"$x\times x + 3\times(-4) = x^2-12$."*
3. $3x\times(-5x)$ — *"$=+15x^2$."*
4. $x^2+x^2$ — *"$=x^4$."*
5. $(8x^2+4x)\div4x$ — *"$8x^2\div4x=2x$, so the answer is $2x+4x=6x$."*

## Set 7 — Bonus / Challenge

2. $(x^2+2x+1) \div (x+1)$
3. $(3x-2)(2x+5) - (x-1)(x+6)$
4. $(x+4)^2-(x-4)^2$
5. $(2x^2-3x+1) \div (2x-1)$

   A) $11x^2+5$  B) $3x^2+5$  C) $3x^2$  D) $3x^2-5$

4. Which of the following is equivalent to the sum of $(x^3+4x^2+2)$ and $(x^2+3x+6)$?
   A) $x^3+5x^2+3x+8$  B) $x^5+5x^2+3x+8$  C) $x^3+4x^2+3x+8$  D) $2x^3+5x^2+3x+8$

5. Which expression is equivalent to $6x^2+18x$?
   A) $6x(x+18)$  B) $x(6x+3)$  C) $6x(x+3)$  D) $6(x^2+18x)$

6. Which expression is equivalent to $(5x^2+3)-(2x^2-4)$?
   A) $3x^2-1$  B) $7x^2-1$  C) $3x^2-7$  D) $3x^2+7$

7. Which expression is equivalent to $8x-(3x+2x)$?

9. Which expression is equivalent to $(2x+5)+(3x-9)$?

12. Which expression is equivalent to $(x^2+6x+9)-(x^2+4)$?
    A) $6x+5$  B) $6x+13$  C) $6x-5$  D) $2x^2+6x+5$

13. If $y=2x-1$, which expression is equivalent to $3y+x$?
    A) $3x-1$  B) $7x+3$  C) $7x-3$  D) $6x-3$

14. Which expression is equivalent to the sum of $(3x^2-x)$ and $(-x^2+5x-2)$?

15. Which expression is equivalent to $12x^3-8x^2$?
    A) $4x(3x^2-2)$  B) $4x^2(3x-8)$  C) $4x^2(3x+2)$  D) $4x^2(3x-2)$
