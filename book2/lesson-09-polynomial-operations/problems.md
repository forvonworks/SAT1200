## Set 6 — Spot the Error

1. $(x^2+3x) - (x^2-2x+5)$ — *"$x^2+3x-x^2-2x+5=x+5$."*
2. $(x+3)(x-4)$ — *"$x\times x + 3\times(-4) = x^2-12$."*
3. $3x\times(-5x)$ — *"$=+15x^2$."*
4. $x^2+x^2$ — *"$=x^4$."*
5. $(8x^2+4x)\div4x$ — *"$8x^2\div4x=2x$, so the answer is $2x+4x=6x$."*

**Set 6:**
1. Error — only the first term's sign was flipped; every term inside the
   second parentheses must flip. Correct: $5x-5$.
2. Error — only the First and Last terms were multiplied (incomplete FOIL);
   the Outer and Inner cross terms were skipped. Correct: $x^2-x-12$.
3. Error — negative × negative should give a positive coefficient, but here
   it's positive × negative, which gives negative. Correct: $-15x^2$.
4. Error — exponents were added as if multiplying; this is addition of like
   terms, so the exponent stays the same. Correct: $2x^2$.
5. Error — only the first term was divided by $4x$; the second term must be
   divided too. Correct: $2x+1$.
