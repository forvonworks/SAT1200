## Set 1 — Slope from Two Points (Pure Drill)

1. $(1,2)$ and $(4,11)$

4. $(-2,-3)$ and $(2,5)$
5. $(0,0)$ and $(5,15)$
6. $(6,1)$ and $(2,9)$

## Set 5 — Context (Interpreting Slope & Intercept)

1. $C(x)=2000x+5000$ (taxi fare, so'm, $x$ = km). Find $C(10)$.
2. Using the same $C(x)$: for what $x$ does $C(x)=35000$?
3. $V(x)=-5x+60$ (tank volume, liters, draining). Find $V(8)$.
4. Using the same $V(x)$: for what $x$ is the tank empty ($V(x)=0$)?
5. A line has slope $4$ and $y$-intercept $-7$. Find its value at $x=3$.
6. A plant's height (cm) after $x$ weeks follows a line through $(2,10)$ and
   $(5,19)$. Find the plant's height at week $0$.

## Set 6 — Spot the Error

1. Find the slope through $(2,5)$ and $(6,13)$ — *"Yechim: $m=\frac{6-2}{13-5}=\frac{4}{8}=\frac12$."*
2. $y=5x-3$ — *"Qiyalik $-3$, kesilgan nuqta $5$."*
3. Find a line perpendicular to $y=2x+1$ — *"Perpendikulyar chiziqning
   qiyaligi ham $2$ bo'ladi, chunki ular kesishadi."*
4. Line through $(3,4)$, slope $-2$ — *"$y-4=-2(x-3) \Rightarrow y-4=-2x-6
   \Rightarrow y=-2x-2$."*
5. $V(x)=-4x+40$ — *"Tank $x=10$ da to'la bo'ladi, chunki $V(10)=0$."*

## Set 7 — Bonus / Challenge

1. Find the equation of the line through $(1,2)$ parallel to the line through
   $(0,0)$ and $(3,9)$.
2. A line passes through $(-2,5)$ and is perpendicular to a line with slope
   $\frac23$. Find its equation.
3. For what value of $k$ does $y=kx+4$ pass through $(3,13)$?
4. $y=mx+5$ and $y=3x+b$ are the same line, passing through $(2,11)$. Find
   $m$ and $b$.
5. A line is parallel to $y=-2x+1$ and has the same $y$-intercept as
   $y=5x-7$. Write its equation.

## Answer Key

**Set 1:** 1) $3$  2) $-3$  3) $0$  4) $2$  5) $3$  6) $-2$

**Set 2:** 1) $\frac34$  2) $-\frac32$  3) $-1$  4) $\frac54$  5) $-\frac23$  6) $2$

**Set 3:** 1) $y=4x-1$  2) $y=-2x+5$  3) $y=3x-5$  4) $y=-2x+2$  5) $y=\frac12x-3$  6) $y=x-3$

**Set 4:** 1) $y=3x+5$  2) $y=-4x+5$  3) $y=-\frac12x+3$  4) $y=3x+6$  5) $y=-2$  6) $y=7$

**Set 5:** 1) $25000$  2) $15$  3) $20$  4) $12$  5) $5$  6) $4$

**Set 6:**
1. Error — inverted the formula ($\Delta x/\Delta y$ instead of
   $\Delta y/\Delta x$). Correct: $m=2$.
2. Error — swapped slope and $y$-intercept. Correct: slope $=5$, $y$-intercept $=-3$.
3. Error — used the same slope instead of the negative reciprocal. Correct:
   slope $=-\frac12$.
4. Error — sign mistake distributing $-2(x-3)$: it's $-2x+6$, not $-2x-6$.
   Correct: $y=-2x+10$.
5. Error — $V(x)=0$ means the tank is **empty**, not full; the sign/context
   meaning was misread, not a computation error.

**Set 7:** 1) $y=3x-1$  2) $y=-\frac32x+2$  3) $k=3$  4) $m=3$, $b=5$  5) $y=-2x-7$
