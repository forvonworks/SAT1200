## Set 1 — Multi-Step Equations (Book 2 Depth)

Solve for $x$:

1. $\dfrac{1}{2}(x+4) = x - 1$
2. $3(x-2) = 2(x+1)$
3. $\dfrac{2}{3}x + 1 = \dfrac{1}{3}x + 5$
4. $5 - 2(x-3) = x + 1$
5. $\dfrac{3}{4}(x-4) = 2x - 7$
6. $4(x+1) - 3 = 2(x+5)$

## Set 2 — "What's Actually Asked" Trap Set

Solve the equation, then answer the question actually asked — **not** just
the value of $x$.

1. If $3x+5=20$, what is $6x+10$?
2. If $2(x-3)=10$, what is $x-3$?
3. If $4x-7=9$, what is $2x$?
4. If $\dfrac{x+2}{3}=5$, what is $x+2$?
5. If $5x+1=26$, what is $10x+2$?
6. If $3(2x+1)=21$, what is $2x+1$?

## Set 3 — Inequalities (Sign-Flip Awareness)

Solve for $x$:

1. $2x+3<11$
2. $-4x+1 \ge 13$
3. $5-x \le 8$
4. $\dfrac{1}{2}x-3>1$
5. $-3(x-2)<9$
6. $7-3x \ge -5$

## Set 4 — Compound Inequalities

Solve for $x$:

1. $-2 < x+3 \le 7$
2. $3x-1<-4$ or $3x-1>8$
3. $-5 \le 2x+1 < 9$
4. $x-4<-6$ or $x-4>2$
5. $-1 < \dfrac{x+1}{2} \le 3$
6. $2x+3<1$ or $2x+3>9$

## Set 5 — Word-Phrase Translation

Translate into an inequality, then solve:

1. A number increased by 5 is at least 12. (Find the number.)
2. Three times a number is no more than 21.
3. A number decreased by 4 is less than 10.
4. Twice a number, decreased by 3, is at least 7.
5. A number is at least $-1$ and at most $5$. (Just write the compound inequality — no solving needed.)
6. Five less than twice a number is no more than 15. What is the **largest possible integer** value of the number?

## Set 6 — Spot the Error

Each item has exactly one broken step. Name the error and give the correct answer.

1. $-2x>8$ — *"Divide both sides by $-2$: $x>-4$."*
2. $x-5>2$ — *"There's a negative number, so flip the sign: $x<7$."*
3. If $4x-1=15$, what is $4x$? — *"$x=4$, so the answer is $4$."*
4. $-2(x-3)<10$ — *"Distribute: $-2x-6<10$, so $x>-8$."*
5. $-4<2x<8$ — *"Divide the middle and right side by 2: $-4<x<4$."*

## Set 7 — Bonus / Challenge (timed, hardest)

1. If $\dfrac{2}{3}(x-3)=x-5$, find $x$, then find $3x$.
2. Solve $-5 < 3x+1 \le 10$. State the compound inequality, then give the **smallest integer** value of $x$ that satisfies it.
3. Seven minus twice a number is at least $-3$. What is the **largest possible value** of the number?
4. Solve $4(x-1)-2x = 3(x+2)-10$ for $x$, then find $x+2$.
5. Solve $-6 \le -2(x-1) < 4$.

## Answer Key

**Set 1:** 1) $x=6$  2) $x=8$  3) $x=12$  4) $x=\frac{10}{3}$  5) $x=\frac{16}{5}$  6) $x=\frac{9}{2}$

**Set 2:** 1) $40$  2) $5$  3) $8$  4) $15$  5) $52$  6) $7$

**Set 3:** 1) $x<4$  2) $x \le -3$  3) $x \ge -3$  4) $x>8$  5) $x>-1$  6) $x \le 4$

**Set 4:** 1) $-5<x \le 4$  2) $x<-1$ or $x>3$  3) $-3 \le x<4$  4) $x<-2$ or $x>6$  5) $-3<x \le 5$  6) $x<-1$ or $x>3$

**Set 5:** 1) $x+5 \ge 12 \Rightarrow x \ge 7$  2) $3x \le 21 \Rightarrow x \le 7$  3) $x-4<10 \Rightarrow x<14$  4) $2x-3 \ge 7 \Rightarrow x \ge 5$  5) $-1 \le x \le 5$  6) $2x-5 \le 15 \Rightarrow x \le 10$, largest integer $=10$

**Set 6:**
1. Error — $8 \div (-2)$ should flip the sign (dividing by a negative), but the direction shown is backwards for this specific flip. Correct: $x<-4$.
2. Error — no multiplication/division by a negative happened (only subtraction), so the sign should **not** flip. Correct: $x>7$.
3. Error — reported $x$ instead of $4x$. Correct: $x=4$, so $4x=16$.
4. Error — distributed $-2 \times (-3)$ as $-6$ instead of $+6$ (sign error in distribution). Correct: $-2x+6<10 \Rightarrow x>-2$.
5. Error — divided the middle and right side by 2 but left the $-4$ un-divided. Correct: $-2<x<4$.

**Set 7:** 1) $x=9$, $3x=27$  2) $-2<x \le 3$, smallest integer $=-1$  3) $x \le 5$, largest value $=5$  4) $x=0$, $x+2=2$  5) $-1<x \le 4$
