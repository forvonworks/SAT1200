# Book 2 — Lesson 4: Word-Problem Translation & Modeling — Problem Sets

**Source content file**, paired with `concepts.md`. Set 1 deliberately asks
for translation only — no solving — to check the translation skill on its
own, the way `concepts.md` argues it should be taught. All solved answers
verified by a `sympy` script, not hand-computed.

---

## Set 1 — Translate Only (do not solve)

For each situation, identify the expression, equation, or inequality that
represents it. Do not solve for a numeric value.

1. Which expression represents the sum of a number $x$ and $9$?
2. Which expression represents a value $7$ less than a number $n$?
3. Which expression represents a number $y$ decreased by $12$?
4. Which expression represents twice a number $x$, increased by $5$?
5. Which expression represents the product of a number $n$ and $4$,
   decreased by $3$?
6. Which expression represents a value $5$ more than three times a
   number $x$?
7. Which inequality represents the statement: a number $n$ is at
   least $10$?
8. Which inequality represents the statement: a number $x$, decreased
   by $6$, is no more than $20$?

## Set 2 — Translate & Solve (one-step)

1. Seven less than a number $n$ is $15$. What is the value of $n$?
2. A number $x$ increased by $9$ is $23$. What is the value of $x$?
3. Twice a number $y$ is $36$. What is the value of $y$?
4. A number decreased by $8$ is $15$. What is the number?
5. Fifteen less than a number $m$ is $7$. What is the value of $m$?
6. The quotient of a number $k$ and $4$ is $9$. What is the value of $k$?

## Set 3 — Translate & Solve (two-step)

1. Five more than twice a number $x$ is $17$. What is the value of $x$?
2. Eight less than three times a number $n$ is $19$. What is the
   value of $n$?
3. Twice the sum of a number $y$ and $4$ is $26$. What is the value of $y$?
4. Seven less than half a number $k$ is $3$. What is the value of $k$?
5. Three less than four times a number $m$ equals twice the number,
   increased by $9$. What is the value of $m$?
6. A number $x$, decreased by $6$, is doubled to get $28$. What is the
   value of $x$?

## Set 4 — Full Word Problems (modeling)

1. A rectangle's length is $2$ more than three times its width. The
   perimeter is $44$. What is the width of the rectangle?
2. The sum of two consecutive integers is $45$. What is the smaller
   of the two integers?
3. Maria is $4$ years older than twice her brother's age. The sum of
   their ages is $31$. What is her brother's age?
4. A shirt costs \$8 more than twice the cost of a hat. Together they
   cost \$38. What is the cost of the hat?
5. A number is increased by $20\%$ of itself to get $72$. What is the
   original number?

## Set 5 — Inequality Translation & Solve

1. A number decreased by $5$ is at least $10$. What are the possible
   values of the number?
2. Three times a number is no more than $21$. What are the possible
   values of the number?
3. Five more than a number is less than $12$. What are the possible
   values of the number?
4. Twice a number, decreased by $4$, is at least $10$. What are the
   possible values of the number?
5. Which inequality represents the statement: a number $x$ is more
   than $8$?

## Set 6 — Spot the Error (the reverse-order trap, every time)

Each item is mistranslated using the Concept 2 trap. Name the error and
give the correct translation (and solution, where one is asked for).

1. Which expression represents "$9$ less than a number $x$"? — *shown
   as* $9-x$.
2. "Fifteen less than a number $n$ equals $20$. What is the value
   of $n$?" — *shown as* $15-n=20$.
3. Which expression represents "$6$ subtracted from a number $y$"? —
   *shown as* $6-y$.
4. Which inequality represents "a number $x$ is less than $10$"? —
   *shown as* $10-x$.
5. "Twice the difference of a number and $3$ is $10$. What is the
   number?" — *shown as* $2n-3=10$.

## Set 7 — Bonus / Challenge (timed, multi-step)

1. The sum of three consecutive even integers is $90$. What is the
   **largest** of the three integers?
2. A rope is cut into two pieces. One piece is $5$ meters longer than
   twice the other. The total length is $35$ meters. What is the
   length, in meters, of the **shorter** piece?
3. John has \$15 more than twice as much money as Maria. Together they
   have \$120. How much money does **John** have?
4. A number increased by $30\%$ of itself, then decreased by $5$,
   equals $47$. What is the original number?
5. Twice the sum of a number and $7$ is $10$ less than five times the
   number. What is the number?

## Answer Key

**Set 1:**
1. $x+9$
2. $n-7$
3. $y-12$
4. $2x+5$
5. $4n-3$
6. $3x+5$
7. $n\geq10$
8. $x-6\leq20$

**Set 2:** 1) $n=22$  2) $x=14$  3) $y=18$  4) $x=23$  5) $m=22$  6) $k=36$

**Set 3:** 1) $x=6$  2) $n=9$  3) $y=9$  4) $k=20$  5) $m=6$  6) $x=20$

**Set 4:**
1. width $=5$ (length $=17$)
2. smaller integer $=22$
3. brother's age $=9$
4. hat $=\$10$
5. original number $=60$

**Set 5:** 1) $x\geq15$  2) $x\leq7$  3) $x<7$  4) $x\geq7$  5) $x>8$

**Set 6:**
1. Error — read left to right instead of reversing order for "less than."
   Correct: $x-9$.
2. Error — same reversal, applied to an equation. Correct: $n-15=20$,
   so $n=35$ (not $n=-5$).
3. Error — "subtracted from" reverses order the same way "less than"
   does: "$A$ subtracted from $B$" means $B-A$. Correct: $y-6$.
4. Error — "is less than" is a *comparison* (Concept 3), not the
   reverse-order subtraction phrase (Concept 2); no subtraction happens
   at all. Correct: $x<10$.
5. Error — "the difference of a number and 3" must be grouped in
   parentheses before doubling; only the $n$ was doubled, not the whole
   difference. Correct: $2(n-3)=10$, so $n=8$.

**Set 7:** 1) largest $=32$  2) shorter piece $=10$ m  3) John $=\$85$
4) original number $=40$  5) the number $=8$
