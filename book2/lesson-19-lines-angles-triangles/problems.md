## Set 1 — Complementary, Supplementary & Vertical Angles

5. Two supplementary angles measure $4x+10$ and $2x+20$. Find $x$, then find both angles.

## Set 3 — Parallel Lines Cut by a Transversal

$\ell_1 \parallel \ell_2$, cut by transversal $t$ at $P$ (on $\ell_1$) and $Q$ (on $\ell_2$).

1. $P$'s lower-right angle is $72°$. Find $Q$'s upper-left angle.
2. $P$'s lower-left angle is $96°$. Find $Q$'s upper-right angle.
3. $P$'s lower-right angle is $130°$. Find $Q$'s upper-right angle.
4. $P$'s upper-right angle is $108°$. Find $Q$'s upper-right angle.
5. $P$'s lower-left angle is $85°$. Find $Q$'s lower-left angle.
6. Lines $m$ and $n$ are cut by a transversal — **$m \parallel n$ is NOT stated or marked**.
   One angle measures $85°$ and the angle in the alternate-interior position measures
   $95°$. Can you conclude $m \parallel n$? What, if anything, can you conclude?

## Set 5 — Mixed: Angles + Similarity

1. In $\triangle ABC$, $\angle A=50°$, $\angle B=70°$. Find $\angle C$. Separately,
   $\triangle ABC \sim \triangle DEF$ and $DE = 2\times AB$; if $AB=6$, find $DE$ and
   state $\angle D$ (no new computation needed for the angle — explain why).
2. Two triangles have $\angle A=\angle D=65°$ and $\angle B=\angle E=80°$. Are the
   triangles similar? If so, by which criterion? Find $\angle C$ and $\angle F$.
3. $\triangle ABC \sim \triangle DEF$ by SAS: $AB=8$, $DE=12$, $\angle A=\angle D=40°$,
   $AC=10$. Find $DF$.
4. In $\triangle ABC$, $D$ is on $AB$ and $E$ is on $AC$, with $DE \parallel BC$.
   $AD=4$, $DB=6$, $AE=6$. Find $EC$. (Hint: $DE\parallel BC$ makes $\triangle ADE \sim
   \triangle ABC$.)
5. A $1.8$ m person casts a $2.4$ m shadow. At the same moment, a flagpole casts a $9.6$ m
   shadow. Find the flagpole's height.
6. Two triangles both have angle measures $55°$, $60°$, $65°$ (listed in different
   orders, no name-correspondence given). The first triangle's side opposite its $55°$
   angle is $5$; the second triangle's side opposite its $55°$ angle is $10$. Are the
   triangles similar? Find the scale factor.

## Set 6 — Spot the Error

Each item has exactly one broken step. Name the error, say which rule it breaks, and
give the correct answer.

1. $\ell_1\parallel\ell_2$. $P$'s lower-right angle is $70°$. Find $Q$'s upper-left angle.
   *Noto'g'ri yechim:* "Bular bir tomonlama ichki burchaklar, demak yig'indisi $180°$:
   $180-70=110°$."
2. Uchburchak burchaklari $2x, 3x, 4x$. $x$ ni toping.
   *Noto'g'ri yechim:* "$2x+3x+4x=360$ (chunki burchaklar yig'indisi $360°$), $9x=360$,
   $x=40$."
3. $\triangle ABC\sim\triangle DEF$. $AB=6$, $BC=9$, $AC=12$, $DE=8$. $EF$ ni toping.
   *Noto'g'ri yechim:* "$EF$ $AC$ ga mos keladi, shuning uchun $EF=AC\times\frac{DE}{AB}
   =12\times\frac{8}{6}=16$."
4. Ikki burchak komplementar (to'ldiruvchi). Biri $65°$. Ikkinchisini toping.
   *Noto'g'ri yechim:* "Komplementar burchaklar yig'indisi $180°$, demak ikkinchisi
   $180-65=115°$."
5. $\ell_1\parallel\ell_2$. $P$'s upper-right angle is $112°$ (mos burchaklar). $Q$'s
   upper-right angle ni toping.
   *Noto'g'ri yechim:* "Mos burchaklar yig'indisi $180°$ ga teng bo'ladi, demak
   $180-112=68°$."

## Set 7 — Bonus / Challenge (timed, multi-step)

1. In $\triangle ABC$, $\angle A=3x$, $\angle B=2x+10$, $\angle C=x+20$. Find $x$ and all
   three angles, then classify the triangle as acute, right, or obtuse.
2. $\ell_1\parallel\ell_2$. $P$'s lower-left angle is $4y+10$. $Q$'s upper-left angle is
   $6y-50$. These form a bir tomonlama ichki burchaklar (co-interior) pair. Find $y$,
   then find both angles.
3. $\triangle ABC \sim \triangle DEF$. The perimeter of $\triangle ABC$ is $30$, with
   $AB:BC:AC = 2:3:5$. $DE=10$. Find the perimeter of $\triangle DEF$ (and $EF$, $DF$).
4. An isosceles triangle has vertex angle $3x-10$ and each base angle $x+15$. Find $x$,
   all three angles, and the measure of the exterior angle formed by extending one base
   side beyond a base angle (the angle supplementary to that base angle).
5. A $3$ m stick casts a $4$ m shadow. At the same time, a tree casts a $16$ m shadow.
   (a) Find the tree's height using similar triangles. (b) Find the straight-line
   distance from the top of the tree to the tip of its shadow.

## Answer Key

**Set 1:** 1) $53°$  2) $68°$  3) $74°$  4) $x=18$; angles $36°,54°$  5) $x=25$; angles
$110°,70°$  6) $x=20$; angle $=75°$

**Set 2:** 1) $65°$  2) $55°$  3) $x=60°$  4) $x=20$; angles $40°,60°,80°$  5) $x=40$;
angles $50°,60°,70°$  6) $x=24$; base angles $48°,48°$; vertex $84°$

**Set 3:** 1) $72°$ (almashinuvchi ichki — equal)  2) $96°$ (almashinuvchi ichki — equal)
3) $50°$ (bir tomonlama ichki — $180-130$)  4) $108°$ (mos burchaklar — equal)
5) $85°$ (mos burchaklar — equal)  6) No — if $m\parallel n$, the alternate-interior
angles would have to be equal ($85°=95°$), but they are not, so $m$ is **not** parallel
to $n$. (A clean demonstration that the rule only applies when parallelism is given —
here it's actually used to disprove parallelism.)

**Set 4:** 1) scale $\frac32$; $EF=9$, $DF=12$  2) scale $3$; $MN=36$, $LN=39$
3) scale $2$; $AB=14$, $AC=22$  4) scale $\frac52$; $LM=35$, $KM=40$
5) $UV=12$, $VW=15$, $UW=21$  6) scale $\frac32$; perimeter $=36$

**Set 5:** 1) $\angle C=60°$; $DE=12$; $\angle D=\angle A=50°$ (similar triangles have
equal corresponding *angles* regardless of the size/scale factor — only the sides scale)
2) Yes, similar by AA; $\angle C=\angle F=35°$  3) $DF=15$  4) $EC=9$  5) $7.2$ m
6) Yes (AA — same three angle measures); scale factor $=2$

**Set 6:**
1. Error — these are **almashinuvchi ichki** (alternate interior, opposite sides of the
   transversal: P right, Q left), not bir tomonlama ichki (co-interior, same side) —
   alternate interior angles are **equal**, not supplementary. Correct: $70°$.
2. Error — a triangle's angles sum to $180°$, not $360°$. Correct: $9x=180$, $x=20$.
3. Error — mismatched correspondence: by letter order ($A\leftrightarrow D$,
   $B\leftrightarrow E$, $C\leftrightarrow F$), $EF$ corresponds to $BC$, not $AC$.
   Correct: $EF=BC\times\frac{DE}{AB}=9\times\frac{8}{6}=12$.
4. Error — complementary angles sum to $90°$, not $180°$ (that's supplementary).
   Correct: $90-65=25°$.
5. Error — corresponding angles are **equal**, not supplementary. Correct: $112°$.

**Set 7:** 1) $x=25$; $\angle A=75°,\angle B=60°,\angle C=45°$ — all under $90°$, so
**acute**  2) $y=22$; $P=98°$, $Q=82°$ (check: $98+82=180$)  3) $AB=6,BC=9,AC=15$;
scale $=\frac53$; $EF=15$, $DF=25$; perimeter of $DEF=50$  4) $x=32$; vertex $=86°$,
base angles $=47°,47°$; exterior angle $=180-47=133°$  5) (a) height $=12$ m
(b) hypotenuse $=\sqrt{12^2+16^2}=\sqrt{400}=20$ m
