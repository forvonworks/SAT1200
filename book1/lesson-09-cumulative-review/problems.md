## Set 7 — Spot the Error

Each item mixes two Book 1 lessons and has exactly one broken step. Name the
error, say which lesson's rule it breaks, and give the correct answer.

1. $\dfrac{1}{2}x + 3 = 7$ — *"$\frac12 x = 7+3=10$, shuning uchun $x=20$."*
2. $3(x-2)=9$ — *"$3x-2=9$, shuning uchun $3x=11$, $x=\frac{11}{3}$."*
3. $f(x)=x^2-2x$, find $f(-3)$ — *"$f(-3)=(-3)^2-2(-3)=9-6=3$."*
4. $0.4x = 24$ — *"$x = 24\times0.4=9.6$."*
5. $2(x+1)-x=9$ — *"$2x+1-x=9$, $x+1=9$, $x=8$."*

**Set 7:**
1. Error — added $3$ to both sides instead of subtracting (equation-solving:
   inverse operation misapplied). Correct: $\frac12x=4$, $x=8$.
2. Error — distributed the $3$ onto $x$ but not onto $-2$ (algebraic
   expressions: incomplete distribution). Correct: $3x-6=9$, $x=5$.
3. Error — treated $-2\times(-3)$ as $-6$ instead of $+6$ (signed numbers:
   two negatives multiply positive). Correct: $9+6=15$.
4. Error — multiplied instead of dividing to isolate $x$ (equation-solving).
   Correct: $x=24\div0.4=60$.
5. Error — distributed the $2$ only onto $x$, not onto the $+1$ (algebraic
   expressions: incomplete distribution). Correct: $2x+2-x=9$, $x=7$.

**Set 8:** 1) $x=\frac{28}{3}$  2) $-5$  3) $x=\frac52$  4) $x=4$  5) $k=2$, $b=5$, $f(0)=5$
