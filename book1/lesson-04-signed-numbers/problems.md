## Set 6 — Spot the Error

what rule it breaks, and give the correct final answer.

2. $(-5) \times (-6)$ — *"Noto'g'ri yechim: $-30$."*
3. $-(10 - 4)$ — *"Noto'g'ri yechim: $-10-4=-14$."*
4. $(-2) \times (-2) \times (-2)$ — *"Noto'g'ri yechim: barcha ko'paytuvchilar

**Set 6:**
1. Error — the minus-minus (subtracting a negative) was dropped instead of
   turned into addition. Correct: $8-(-3)=8+3=11$.
2. Error — assumed "both negative → result negative," but same-sign
   multiplication gives a **positive** result. Correct: $(-5)\times(-6)=30$.
3. Error — the negative sign was distributed only to the first term inside
   the brackets, not both. Correct: $-(10-4)=-10+4=-6$.
4. Error — ignored that there are **three** (an odd number of) negative
   factors, not an even one; odd count of negatives → negative result.
   Correct: $(-2)\times(-2)\times(-2)=-8$.
5. Error — assumed "both negative → result negative" for division too; same
   sign (both negative) → **positive**. Correct: $(-15)\div(-3)=5$.
