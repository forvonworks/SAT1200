## Set 6 — Spot the Error

Each item has exactly one broken step. Name the mistake, give the correct
answer.

1. $f(x) = 3x + 2$ bo'lsa, $f(5)$ ni toping. — *Noto'g'ri yechim:*
   "$f(5) = f \cdot 5$, $f$ ning qiymati noma'lum, demak javob topib
   bo'lmaydi."
2. $f(x) = x^2$ bo'lsa, $f(-4)$ ni toping. — *Noto'g'ri yechim:*
   "$f(-4) = -4^2 = -16$."
3. $(-3,\ 5)$ nuqtasi qaysi chorakda? — *Noto'g'ri yechim:* "$x = -3$ ni
   musbat deb o'ylab, I chorak" deb javob berilgan.
4. $f(x) = 2x - 5$. Agar $f(x) = 7$ bo'lsa, $x$ ni toping. — *Noto'g'ri
   yechim:* "$2x - 5 = 7 \Rightarrow 2x = 2 \Rightarrow x = 1$."
5. $f(x) = x^2 + 3$ bo'lsa, $f(-2)$ ni toping. — *Noto'g'ri yechim:*
   "$f(-2) = -2^2 + 3 = -4 + 3 = -1$."

**Set 6:**
1. Error: $f$ treated as a number being multiplied, not a function name.
   Correct: $f(5) = 3(5)+2 = 17$.
2. Error: dropped parentheses around the negative input. Correct:
   $f(-4) = (-4)^2 = 16$.
3. Error: misread the sign of $x$. Correct: $x=-3<0, y=5>0 \Rightarrow$
   II chorak.
4. Error: $7+5=12$, not $2$. Correct: $2x=12 \Rightarrow x=6$.
5. Error: dropped parentheses again. Correct: $f(-2)=(-2)^2+3=7$.
