# Book 1 — Lesson 1: Basic Arithmetic & Order of Operations — Practice Sets

**Source content file**, paired with `concepts.md`. Sets build in the order
specified at the bottom of `concepts.md`: pure drill → negatives present →
fraction-bar grouping → absolute-value grouping → mixed/test-density →
spot-the-error (erroneous-example technique) → bonus challenge. All answers
verified by hand below; every problem uses clean integer results except where
the problem's point *is* the non-triviality of the grouping, not the
arithmetic itself.

All expressions use SAT-standard notation (fraction bar for division,
juxtaposition/$\times$ for multiplication) per the notation note in
`concepts.md` Concept 1.

---

## Set 2 — Negative Numbers Present

Negatives appear as given values to substitute, not as a sign-rule lesson
(full signed-number rules are Lesson 4) — the point here is applying the
*order*, not deriving sign arithmetic from scratch.

1. $-3 + 4 \times 2$
2. $(-3 + 4) \times 2$
3. $5 - (-2) \times 3$
4. $(-2)^2 \times 3$
5. $-2^2 \times 3$
6. $10 + (-4) \div 2$
7. $(10 + (-4)) \div 2$
8. $-5 \times (-3) + 2$

*(Problems 4 and 5 are a deliberate pair — same numbers, different placement
of the parentheses around the negative sign. Students should get different
answers and be able to explain why.)*

## Set 6 — Spot the Error

Each item shows a solution with exactly one broken step. Name the step, say
what rule it breaks, and give the correct final answer. (This format directly
targets the documented misconception from `concepts.md`'s Common Mistake box
— seeing the *wrong* reasoning named explicitly is part of the lesson, not
just extra practice.)

1. Ifodani hisoblang: $20 \div 4 \times 5$
   *Noto'g'ri yechim:* 1-qadam: $4 \times 5 = 20$. 2-qadam: $20 \div 20 = 1$.
2. Ifodani hisoblang: $15 - 3 + 4$
   *Noto'g'ri yechim:* 1-qadam: $3 + 4 = 7$. 2-qadam: $15 - 7 = 8$.
3. Ifodani hisoblang: $\dfrac{10 + 2}{2 \times 3}$
   *Noto'g'ri yechim:* "Avval $2\times3=6$, so'ng $2 \div 6 = \frac{1}{3}$,
   so'ng $10 + \frac{1}{3} = 10\frac{1}{3}$."
4. Ifodani hisoblang: $-4^2$
   *Noto'g'ri yechim:* $-4^2 = (-4)^2 = 16$.
5. Ifodani hisoblang: $3 - |5 - 9|$
   *Noto'g'ri yechim:* $3 - 5 - 9 = -11$.

**Set 6:**
1. Error in step 1 — multiplication was done before division even though
   division is leftmost; × and ÷ are equal priority, left to right. Correct:
   $20 \div 4 = 5$, then $5 \times 5 = 25$.
2. Error in step 1 — addition was done before subtraction even though
   subtraction is leftmost; + and − are equal priority, left to right.
   Correct: $15 - 3 = 12$, then $12 + 4 = 16$.
3. Error — treated the fraction bar as grouping only the denominator,
   ignoring that it groups the numerator "$10+2$" too. Correct:
   $\frac{12}{6} = 2$.
4. Error — squared the negative sign along with the 4, but there are no
   parentheses around $-4$, so the exponent applies to $4$ only. Correct:
   $-4^2 = -(4^2) = -16$.
5. Error — subtracted term-by-term through the absolute value bars instead
   of computing inside them first. Correct: $5-9=-4$, $|-4|=4$, $3-4=-1$.
