## Set 6 — Spot the Error

Har bir misolda aynan bitta xato qadam bor. Qaysi qadam xato va nega,
ayting, so'ng to'g'ri javobni toping.

1. $\dfrac{1}{3} + \dfrac{1}{4}$ — *"$\dfrac{1+1}{3+4} = \dfrac{2}{7}$."*
2. $\dfrac{2}{5} + \dfrac{2}{5}$ — *"Suratni saqlab, faqat maxrajlarni
   qo'shamiz: $\dfrac{2}{10}$."*
3. $\dfrac{3}{4} \div \dfrac{2}{5}$ — *"$\dfrac{4}{3} \times \dfrac{2}{5} =
   \dfrac{8}{15}$."*
4. $\dfrac{16}{24}$ ni soddalashtiring — *"2 ga qisqartirib, $\dfrac{8}{12}$
   — tayyor."*
5. $2\tfrac{3}{4}$ ni noto'g'ri kasrga aylantiring — *"$\dfrac{2+3}{4} =
   \dfrac{5}{4}$."*

**Set 6:**
1. Error — treated numerator and denominator as independent sums instead of
   finding a common denominator. Correct: $\dfrac{1}{3} = \dfrac{4}{12}$,
   $\dfrac{1}{4} = \dfrac{3}{12}$, so $\dfrac{4}{12}+\dfrac{3}{12} =
   \dfrac{7}{12}$.
2. Error — with equal denominators, only the numerators are added and the
   denominator stays the same. Correct: $\dfrac{2}{5}+\dfrac{2}{5} =
   \dfrac{4}{5}$.
3. Error — the reciprocal was applied to the first fraction instead of the
   second (the divisor). Correct: $\dfrac{3}{4} \times \dfrac{5}{2} =
   \dfrac{15}{8}$.
4. Error — stopped after one reduction step instead of reducing fully (8 and
   12 still share a factor of 4). Correct: $\dfrac{16}{24} = \dfrac{2}{3}$.
5. Error — added the whole number directly to the numerator instead of
   multiplying by the denominator first. Correct: $3\times4=12$, $12+3=15$,
   so $2\tfrac{3}{4} = \dfrac{11}{4}$.
