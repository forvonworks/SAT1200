# Book 1 — Lesson 6: One-Variable Equations — Practice Sets

**Source content file**, paired with `concepts.md`. Sets build in the order
specified at the bottom of `concepts.md`: one-step → two-step → multi-step
(distribution + like terms) → variable on both sides → mixed/SAT-style
(asks for a derived expression, not just $x$) → spot-the-error → bonus
challenge. Every answer verified by script — see the session's verification
run (`sympy.solve` against each equation, including the derived-expression
checks in Set 5).

## Set 6 — Spot the Error

Each item shows a solution with exactly one broken step. Name the step, say
what rule it breaks, and give the correct final answer.

1. $x - 5 = 12$ — *"1-qadam: ikkala tomonga 5 qo'shiladi: $x = 12$."*
2. $2x - 5 = 9$ — *"1-qadam: $2x = 9 - 5 = 4$."*
3. $-2(x - 3) = 10$ — *"1-qadam: $-2x - 6 = 10$."*
4. $3x + 5 = 20$ — *"1-qadam: $8x = 20$, shuning uchun $x = 2.5$."*
5. $2x + 1 = 11$. Savolda $3x$ ning qiymati so'ralgan. — *"$x = 5$, javob: 5."*

**Set 6:**
1. Error — the $5$ was only added to the right side; it must be added to
   both sides. Correct: $x = 12 + 5 = 17$.
2. Error — moved $-5$ to the right side without flipping its sign (should
   be $+5$). Correct: $2x = 9 + 5 = 14$, so $x = 7$.
3. Error — distributed $-2$ only onto the first term ($-2 \times x = -2x$)
   but not the second ($-2 \times (-3)$ should be $+6$, not $-6$). Correct:
   $-2x + 6 = 10 \Rightarrow -2x = 4 \Rightarrow x = -2$.
4. Error — combined the unlike terms $3x$ and $5$ into $8x$; a variable
   term and a constant term are not like terms. Correct: $3x = 15
   \Rightarrow x = 5$.
5. Error — solved correctly for $x = 5$ but answered with $x$ instead of
   the asked expression $3x$. Correct: $3x = 3(5) = 15$.
